# 2026 全国大学生数学建模竞赛（CUMCM）

> 2026 年高教社杯全国大学生数学建模竞赛工作仓库，用于统一管理题目资料、数据、代码、图表与论文。

## 仓库用途

- 集中存放赛题原文、附件数据与官方说明
- 管理建模、求解、可视化的全部代码，保证结果可复现
- 版本化论文 LaTeX / Word 源文件，避免多人协作时互相覆盖
- 记录建模思路、假设、参数与阶段性结论

## 目录结构（规划）

```text
2026-CUMCM/
├── README.md              # 本文件
├── problem/               # 赛题原文、附件、官方说明
├── data/
│   ├── raw/               # 原始数据（只读，不做修改）
│   └── processed/         # 清洗、整理后的数据
├── src/                   # 建模与求解代码（Python / MATLAB 等）
├── notebooks/             # 探索性分析 Jupyter Notebook
├── figures/               # 论文用图表（矢量图优先）
├── paper/                 # 论文源文件（LaTeX / Word）及模板
├── results/               # 模型输出结果、中间产物
└── docs/                  # 思路记录、会议纪要、参考文献
```

## 分工

| 角色 | 成员 | 主要职责 |
| ---- | ---- | -------- |
| 建模 | 待定 | 问题分析、模型建立、假设与符号说明 |
| 编程 | 待定 | 数据处理、模型求解、灵敏度分析、绘图 |
| 写作 | 待定 | 论文撰写、排版、摘要打磨、格式检查 |

## 竞赛时间线（模板）

| 阶段 | 内容 |
| ---- | ---- |
| Day 1 | 通读赛题、选题、拆解问题、确定整体思路，搭建论文骨架 |
| Day 2 | 数据处理与主模型求解，完成核心结果与图表 |
| Day 3 | 模型检验、灵敏度分析、补充问题，完成论文初稿 |
| Day 4 | 摘要精修、全文校对、格式与提交检查 |

## 环境

- Python 3.x：`numpy`、`pandas`、`scipy`、`matplotlib`、`scikit-learn` 等
- MATLAB（可选）
- LaTeX：推荐使用 CUMCM 官方格式模板（如 `cumcmthesis`）

## 约定

- `data/raw/` 中的原始数据不做任何修改，所有处理结果写入 `data/processed/`
- 代码提交前确保可以从头运行，随机过程固定随机种子
- 图表统一风格，字号与线宽在论文中清晰可读，优先导出 PDF / SVG
- 提交信息用简洁的中文或英文说明改动内容，例如 `feat: 完成问题一模型求解`
