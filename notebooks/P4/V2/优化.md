## 1. 改动一：规划栅格的「幻影格点」——本轮唯一的真 bug

`公共.方向栅格.__init__` 里格点范围原来写死成

```python
内 = np.hypot(X, Y) <= R + 步长 / np.sqrt(2)
```

但**裕度是可以被单独指定的**（`规划裕度 = 28.3`，与它自己的 120 m 步长无关，
因为粗栅格的方格只是「采样位置」）。于是：

| 栅格 | 步长 | 裕度 | 格点铺到半径 |
| --- | ---: | ---: | ---: |
| 判据栅格 | 40 | 28.28 | 1828.3 |
| 规划栅格 | 120 | 28.3 | **1878.3** |

一个格点代表的是「以它为心、半径 = 裕度」的邻域——距离与角度两处保守量都是按这个
邻域算的（引理 E2）。**邻域整个落在目标圆域外的格点里不可能藏源**（附件 2 §1.1：
所有干扰源位于目标区域内），覆盖它没有任何意义。

证据链，全部可复算：

```
用 24 点离线构造覆盖之后
    判据掩码残余 = 0          <- 判空成立
    规划掩码残余 = 59         <- 凭空多出来的
    残余方格的半径 1831.7 ... 1878.3，28/28 个全部 > 1828.3
贪心从零规划
    修正前  31 个锚点 / 巡回 22772 m
    修正后  24 个锚点 / 巡回 19048 m   <- 正好回到离线构造
    修正后这组锚点在判据栅格上的残余 = 0
```

**修法一行**：按自身裕度截断。

```python
半径 = R + self.裕度          # 裕度为 None 时 = 步长/sqrt2，与原式完全等价
内 = np.hypot(X, Y) <= 半径 + 1e-9
```

裕度取默认值时两式恒等，**判据栅格一格不变**，所以 `分析记录.md` 里判空的正确性
论证、以及引理 E2/E3/E4 一个字都不用改。改后重跑：

- `判空几何.py`：判据栅格残余 0、精确判据最大围堵半径 975.12 m、未被围堵格点 0，与改前逐字相同
- `命题与引理.py`：11 条引理反例总数 0，**E4（规划器返回的锚点集一定能清空判据掩码）
  300 样本 0 反例、交白卷 0 次**；判别性对照「规划覆盖 ⇒ 判据覆盖」仍然 812/4000 违规
  ——这条蕴含本来就不成立，正确性靠的是贪心末尾在判据栅格上核残余、不空就补收尾锚点

> **教训**：一个保守量被解耦成参数之后，**所有依赖它的地方都要跟着解耦**。
> 这里「格点范围」和「裕度」本是同一个物理量的两种用法，只改了一处，
> 代价是每局多走 3.7 km、多测 66 次。

## 4. 单独记一条：补测点按路线评分——问题三那条教训的第二件外衣

`选补测点` 的行程项原来是 `|当前→q| + |q→区域中心|`，**没有考虑后面还要走的锚点巡回**。
看起来明显该改成真正的边际代价：走到 q 之后总得奔向「反正要去的下一站」，于是

```python
下一站 = min(|q→清除点|, min over 未走锚点 |q→锚点|)
行程   = |当前→q| + 下一站
```

**实测更差：40 局配对 +261.6 s，$t = +2.74$，专程补测 13.1 → 18.7 次（+43%）。**

原因：这个评分把「离某个锚点近」的**远处**候选也算成便宜，于是专程补测变多，
而且几何更差（离区域远 ⇒ 楔形压不动）。

> 这和问题三 `P3/V2/优化.md §2` 那条 **+848 s** 的「补测顺路闸」是**同一类错误的两件外衣**：
> 那条是按插入代价**拦下**补测，这条是按插入代价**换个地方**补测；
> 共同的错在于**用一个会被自身决策改变的量去当边际代价**——路线本身依赖于选了哪个 q。
> 在滚动时域里，「边际代价」这个概念需要不动点，而这里没有。
>
> 代码保留，`补测按路线` 默认 `False`。

## 6. 副产品：判空的时间-风险前沿（建议进论文）

讨论「能不能为了速度放弃围堵」时算的，本身是个干净的结论。

对位置 $x$，设已在 $p_1\dots p_k$ 得到 `no_signal` 且 $|p_i-x|\le r$，
则「源在 $x$ 却始终收不到」要求定向方向 $u$ 同时满足 $(p_i-x)\cdot u<0$——
这是若干**过原点的开半平面之交，必为一个张角 $L(x)<180^\circ$ 的凸锥**。于是

$$L(x)=0\iff x\text{ 被围堵};\qquad \Pr[\text{定向源藏在 }x]=\frac{L(x)}{360^\circ}$$

贪心最小化 $\int L$，得到（判据半径 985 m，40 m 网格）：

| 锚点数 | 漏掉一个定向源的概率 | 开放巡回 m | 判空秒 |
| ---: | ---: | ---: | ---: |
| 9 | 18.3% | 8919 | 2216 |
| 12 | 9.67% | 11952 | 2966 |
| 15 | 4.45% | 13953 | 3511 |
| 18 | 1.35% | 15824 | 4029 |
| 21 | 0.43% | 16914 | 4391 |
| 24 | 0.12% | 17516 | 4655 |
| **24（可证构造，风险严格 0）** | **0** | 19048 | **4962** |

读法：**风险从 0 放到 1.35%/源只省 930 s；想省 2000 s 就得吃 9.7%/源
（单局按 6.4 个定向源算，46% 概率漏一个）。尾巴便宜，中段极贵。**
「花小钱买点风险」这条路在这个问题上不划算。

（注意这张表只算了锚点。真实策略还有清除点、补测点在缩锥，所以实际风险低于表值——
`策略对照.py` 里「直接套用问题三的判空」那条基线 10 局一个没漏就是这个原因。
要量真实风险必须直接数漏源次数，本轮没做。）

## 10. 给下一轮的三条

1. **改动前先问「这个量会不会被自己的决策改变」。** §4 那条和问题三的顺路闸
   死在同一件事上：滚动时域里没有不动点，插入代价不是边际代价。
2. **一个保守量被抽成参数，就要检查所有依赖它的地方。** §1 那个 bug 藏了整个开发周期，
   因为「格点范围」和「裕度」表面上是两件事，实际是同一个物理量。
3. **继承来的默认值必须在新问题里重测一遍。** ζ = 1.40 在问题三是对的，
   在问题四方向都反了。这次是白捡的 −211 s，下次可能是白丢的。
