## 1. 改动一：规划栅格的「幻影格点」——本轮唯一的真 bug

`公共.方向栅格.__init__` 里格点范围原来写死成

```python
内 = np.hypot(X, Y) <= R + 步长 / np.sqrt(2)
```

但**裕度是可以被单独指定的**（`规划裕度 = 28.3`，与它自己的 120 m 步长无关，
因为粗栅格的方格只是「采样位置」）。于是：

| 栅格 | 步长 | 裕度 | 格点铺到半径 |
| --- | ---: | ---: | ---: |
| 判据栅格 | 40 | 28.28 | 1828.3 |
| 规划栅格 | 120 | 28.3 | **1878.3** |

一个格点代表的是「以它为心、半径 = 裕度」的邻域——距离与角度两处保守量都是按这个
邻域算的（引理 E2）。**邻域整个落在目标圆域外的格点里不可能藏源**（附件 2 §1.1：
所有干扰源位于目标区域内），覆盖它没有任何意义。

证据链，全部可复算：

```
用 24 点离线构造覆盖之后
    判据掩码残余 = 0          <- 判空成立
    规划掩码残余 = 59         <- 凭空多出来的
    残余方格的半径 1831.7 ... 1878.3，28/28 个全部 > 1828.3
贪心从零规划
    修正前  31 个锚点 / 巡回 22772 m
    修正后  24 个锚点 / 巡回 19048 m   <- 正好回到离线构造
    修正后这组锚点在判据栅格上的残余 = 0
```

**修法一行**：按自身裕度截断。

```python
半径 = R + self.裕度          # 裕度为 None 时 = 步长/sqrt2，与原式完全等价
内 = np.hypot(X, Y) <= 半径 + 1e-9
```

裕度取默认值时两式恒等，**判据栅格一格不变**，所以 `分析记录.md` 里判空的正确性
论证、以及引理 E2/E3/E4 一个字都不用改。改后重跑：

- `判空几何.py`：判据栅格残余 0、精确判据最大围堵半径 975.12 m、未被围堵格点 0，与改前逐字相同
- `命题与引理.py`：11 条引理反例总数 0，**E4（规划器返回的锚点集一定能清空判据掩码）
  300 样本 0 反例、交白卷 0 次**；判别性对照「规划覆盖 ⇒ 判据覆盖」仍然 812/4000 违规
  ——这条蕴含本来就不成立，正确性靠的是贪心末尾在判据栅格上核残余、不空就补收尾锚点

> **教训**：一个保守量被解耦成参数之后，**所有依赖它的地方都要跟着解耦**。
> 这里「格点范围」和「裕度」本是同一个物理量的两种用法，只改了一处，
> 代价是每局多走 3.7 km、多测 66 次。

## 4. 单独记一条：补测点按路线评分——问题三那条教训的第二件外衣

`选补测点` 的行程项原来是 `|当前→q| + |q→区域中心|`，**没有考虑后面还要走的锚点巡回**。
看起来明显该改成真正的边际代价：走到 q 之后总得奔向「反正要去的下一站」，于是

```python
下一站 = min(|q→清除点|, min over 未走锚点 |q→锚点|)
行程   = |当前→q| + 下一站
```

**实测更差：40 局配对 +261.6 s，$t = +2.74$，专程补测 13.1 → 18.7 次（+43%）。**

原因：这个评分把「离某个锚点近」的**远处**候选也算成便宜，于是专程补测变多，
而且几何更差（离区域远 ⇒ 楔形压不动）。

> 这和问题三 `P3/V2/优化.md §2` 那条 **+848 s** 的「补测顺路闸」是**同一类错误的两件外衣**：
> 那条是按插入代价**拦下**补测，这条是按插入代价**换个地方**补测；
> 共同的错在于**用一个会被自身决策改变的量去当边际代价**——路线本身依赖于选了哪个 q。
> 在滚动时域里，「边际代价」这个概念需要不动点，而这里没有。
>
> 代码保留，`补测按路线` 默认 `False`。

3. **同心环族**（`1 + n₂@ρ₂ + n₁@ρ₁`，320 个方案）：在**精确**判据（连续方向间隙 ≤ 180°）

## 6. 副产品：判空的时间-风险前沿（建议进论文）

讨论「能不能为了速度放弃围堵」时算的，本身是个干净的结论。

对位置 $x$，设已在 $p_1\dots p_k$ 得到 `no_signal` 且 $|p_i-x|\le r$，
则「源在 $x$ 却始终收不到」要求定向方向 $u$ 同时满足 $(p_i-x)\cdot u<0$——
这是若干**过原点的开半平面之交，必为一个张角 $L(x)<180^\circ$ 的凸锥**。于是

$$L(x)=0\iff x\text{ 被围堵};\qquad \Pr[\text{定向源藏在 }x]=\frac{L(x)}{360^\circ}$$

贪心最小化 $\int L$，得到（判据半径 985 m，40 m 网格）：

| 锚点数 | 漏掉一个定向源的概率 | 开放巡回 m | 判空秒 |
| ---: | ---: | ---: | ---: |
| 9 | 18.3% | 8919 | 2216 |
| 12 | 9.67% | 11952 | 2966 |
| 15 | 4.45% | 13953 | 3511 |
| 18 | 1.35% | 15824 | 4029 |
| 21 | 0.43% | 16914 | 4391 |
| 24 | 0.12% | 17516 | 4655 |
| **24（可证构造，风险严格 0）** | **0** | 19048 | **4962** |

读法：**风险从 0 放到 1.35%/源只省 930 s；想省 2000 s 就得吃 9.7%/源
（单局按 6.4 个定向源算，46% 概率漏一个）。尾巴便宜，中段极贵。**
「花小钱买点风险」这条路在这个问题上不划算。

（注意这张表只算了锚点。真实策略还有清除点、补测点在缩锥，所以实际风险低于表值——
`策略对照.py` 里「直接套用问题三的判空」那条基线 10 局一个没漏就是这个原因。
要量真实风险必须直接数漏源次数，本轮没做。）

## 12. 交会角—收信概率恒等式（本轮的理论产出）

设定向源在 $G$、朝向 $u$ 未知（先验均匀）。已在 $p$ 收到信号，问在 $q$ 能否收到。

在 $p$ 收到 $\iff$ $u$ 落在以 $G\!\to\!p$ 为中心的 $180^\circ$ 弧内；条件化后 $u$ 在该弧上均匀。
在 $q$ 收到要求 $u$ 落在以 $G\!\to\!q$ 为中心的 $180^\circ$ 弧内。两弧交集宽 $180^\circ-\varphi$：

$$\Pr[\text{在 }q\text{ 收到}\mid\text{在 }p\text{ 收到}]=1-\frac{\varphi}{180^\circ},
\qquad \varphi=\text{两检测点对源的交会角}$$

**它把"三角定位要大交会角"与"定向源要小交会角才收得到"钉在同一个量上，而且与距离无关**
（距离是另一条独立约束 $|q-G|\le R_{\text{eff}}$）。问题三没有这个张力——这就是问题四
定位变贵的全部来源。

**保证锥（推论，两行区间代数）**。记 $G\!\to\!p$ 的方位为 $\alpha$、$G\!\to\!q$ 为 $\beta=\alpha+\varphi$：

$$\text{在 }p\text{ 收到}\Rightarrow u\in[\alpha-90^\circ,\alpha+90^\circ],\qquad
\text{在 }q\text{ 落空}\Rightarrow u\notin[\beta-90^\circ,\beta+90^\circ]$$

两者相交得 $u\in[\alpha-90^\circ,\ \alpha+\varphi-90^\circ)$，**宽度恰为 $\varphi$**。
方位为 $\gamma$ 的点能收到 $\iff u\in[\gamma-90^\circ,\gamma+90^\circ]$；
要它对整条残余弧都成立，需

$$\gamma-90^\circ\le\alpha-90^\circ\quad\text{且}\quad
\alpha+\varphi-90^\circ\le\gamma+90^\circ
\ \Longrightarrow\ \alpha+\varphi-180^\circ\le\gamma\le\alpha$$

即**交会角 $\psi=\gamma-\alpha\in[\varphi-180^\circ,\ 0^\circ]$ 的点全都保证收到**，
锥宽 $180^\circ-\varphi$。取中点 $\psi=(\varphi-180^\circ)/2$ 留下 $(180^\circ-\varphi)/2$ 的余量
（$\varphi=90^\circ$ 时取 $-45^\circ$，余量 $45^\circ$）。

> **与镜像必达（引理 D3）的关系**：镜像射线 $s+\lambda(s-q)$ 是这个锥里的一支，
> 但几何最差的一支。取 $\lambda=1$、$d_2=d_0$、$\varphi=90^\circ$ 算一下，
> 镜像点在 $(2d_0,-d_0)$，交会角只有 $\arctan(1/2)=26.6^\circ$、距源 $2.24d_0$；
> 而锥里可取的 $-45^\circ$ 点距源只有 $d_0$。**同一条定理，解集用全和取一个解，差别就在这里。**

| 第一次取 $\varphi$ | 收到概率 | 落空后保证锥宽 |
| ---: | ---: | ---: |
| 45° | 0.75 | 135° |
| 60° | 0.67 | 120° |
| 90° | 0.50 | 90° |

**最坏两次检测，两次都能拿到好几何**——这比"镜像必达"那条路强得多。

## 13. 由恒等式诊断出的候选点缺陷，以及两条改动

把 `补测点候选` 的三族换算成交会角（$d_0$ = 信号点到估计源位的距离）：

| 候选族 | 到源距离 | 交会角 |
| --- | --- | ---: |
| p 锚定正横对，$t=0.2/0.4/0.7/1.0\times d_0$ | $\sqrt{d_0^2+t^2}$ | 11° / 22° / 35° / **45°** |
| 镜像必达 $s+\lambda(s-q)$ | $2\!\sim\!3\,d_0$ | **27°~33°** |

**缺陷一：整个候选集的交会角上限只有 45°。** 两条 $\pm1^\circ$ 楔形在 $\varphi$ 处相交，
横向尺度 $\approx 2\delta d/\sin\varphi$；$d=800$ 时 $2\delta d=28$ m，
$\varphi=90^\circ$ 给 $R_{\min}\approx20$ m（**直接可清除**），$\varphi=45^\circ$ 给 $30\!\sim\!35$ m（卡在阈值上）。

**缺陷二：交会角最大的那个候选距离反而没保证。** $t=d_0$ 的点到源是 $\sqrt2 d_0$，
$d_0>707$ m 就超出题给保证的 1000 m——等于同时赌方向和距离。

### 13.1 改动三：保证锥（**采纳**）

`选补测点` 原来是 `候选表 = 保证族 if 保证族 else 普通候选`，而 `保证族` 只有镜像射线上
的 8 个点。按 §12，落空后的保证集是**整个对侧锥**，镜像射线只是其中几何最差的一支。
改成：`保证族 + {普通候选里 把握 = 1 的}`（`收信评估器` 算的是精确可行集），
镜像射线留作兜底，"最坏两次检测"的性质不丢。

### 13.2 改动四：环绕候选（**采纳，但必须带门**）

新增候选族：以估计源位为心、半径 $\rho\le950$ m 的圆上、与 $p$ 方位差 $\psi$ 的点。
它把两条约束**解耦**：$\rho$ 管距离（保证），$\psi$ 直接就是交会角。而且
总行程 $p\to q\to G$ 与正横族**完全相同**：

| 方案 | $p\to q$ | $q\to G$ | 合计 | $\varphi$ | $\lvert q-G\rvert$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| 正横 $t=d_0$ | $d_0$ | $1.41d_0$ | $2.41d_0$ | 45° | $1.41d_0$（可能超 1000） |
| 环绕 $\rho=d_0,\psi=90^\circ$ | $1.41d_0$ | $d_0$ | $2.41d_0$ | **90°** | $d_0$（**保证**） |

**但单开更差：32 局 +225 s（$t=1.76$）、路程 +1094 m。** 原因是环绕点的有效性取决于
$\hat d$ 准不准，而只有一条方位线时区域是一条长条、$\hat d$ 的不确定度与它本身同量级，
此时环绕点等于随便跑到远处。加一道门——**至少两条方位线才启用**——之后转正。
（门设在 1 / 2 / 3 条三档实测几乎无差别，取 2。）

### 13.3 改动五：扫清代价比较（**做了，有害，默认关闭**）

立意：附件 2 §2.4 说清除成功只与距离有关、**与朝向无关**，所以清除是问题四里唯一的
"无条件"动作；而检测按 §12 有 $\varphi/180$ 的失败率。于是"铺一层 20 m 清除盘打完"
与"再补测一次"应当直接比秒数，而不是卡一个固定的 $R_{\min}$ 阈值：

$$\text{扫清}\approx\frac{n+1}{2}\Big(3+\frac{20\sqrt2}{5}\Big)+\frac{|\text{当前}\to\text{首枪}|}{5},
\qquad \text{补测}=\text{选补测点的评分}$$

**实测有害**：单局触发 99 次、总时间 $7185\to16683$ s、还出现未决 1。
原因是补测评分里"压不下去的罚"最大到 460 s，区域一大就比扫清估价还高，
于是一旦区域偏大就滑进扫清模式，而扫清的枪数与行程随区域**面积**增长。
**这条比较缺一个"区域别太大"的前提；加上之后它就退化成盲清阈值本身。**

（附带踩到一个性能坑：我在这段里对扫清点阵跑了 `开放TSP`，而它每轮规划、
每个未定位频道都要走一遍，单局算时从 1 s 拖到 38 s。改成取最近点即可——
**只执行第一枪就重规划，根本不需要排序。**）

### 13.4 改动六：盲清阈值 28 → 40（**采纳**）

§13.3 的立意是对的，只是不该做成无前提的比较。退回阈值形式、在**校准后的分布**下
重扫：40 这一档 100 局再省 100 s，专程补测 12.7 → 10.2 次；55 那一档清除率掉到 0.9974。
取 40（上限 5 → 7）。

## 16. 全向可判性的单侧性，与「双向围堵」对偶

复盘时注意到 `判定为全向` 在八次官方日志里**全部是 0**。查下去这不是缺陷，
是问题四的一条结构性事实，而且它与判空互为对偶——**值得进论文**。

`公共.频道信念.更新定向性` 的两条判据：

| 判定 | 条件 | 触发难度 |
| --- | --- | --- |
| **定向** | 全向假设下可行集为空（有一个「保证接收距离内却收不到」的点） | **一次就够** |
| **全向** | 引理 D2：可行集 $\subseteq\operatorname{int}\operatorname{conv}(\mathcal S_c)$ | **需要 $\ge3$ 个信号点把源围起来** |

第二条**不是保守，而是充要的**：位置 $x$ 有可能是定向源
$\iff$ 存在过 $x$ 的半平面同时包含全部信号点 $\iff x\notin\operatorname{int}\operatorname{conv}(\mathcal S_c)$。
所以要否掉定向分支，只能真的把 $x$ 围起来。

于是得到一对镜像结论：

$$\textbf{判空}：\text{用}\ \textbf{无信号点}\ \text{围住候选位置}\qquad\Longleftrightarrow\qquad
\textbf{判全向}：\text{用}\ \textbf{信号点}\ \text{围住源}$$

**两者都是「围堵」，只是见证者的类型相反。** 问题四里「围堵」这件事出现了两次。

**实测后果。** 策略拿到 2~3 条方位线就够定位清除了，没有动机再绕到背面补一次
「收得到」的检测，所以这个分类器**注定不触发**：八局官方日志 0/8，
事后用真位置重判也一样（§11.3）。

**副作用是可量化的。** `收信评估器` 里先验取 `1.0 / 0.0 / 全向先验(0.5)` 三档，
「全向」永不触发 ⟹ 真全向的频道一直按 0.5 计，白吃 $(1-\text{把握})\times$ 空测罚。
但把先验重扫一遍（0.15 / 0.30 / 0.65，§11.1）全在噪声里，
说明**这个副作用的量级小于 100 s**，不值得为它去专程绕到背面补测。

**论文口径。** 因此报告一局的定向源个数时**只能给下界**，不能写成
「全向 $x$ 个、定向 $y$ 个」。`事后定向性.py` 给出的就是这个下界。
