六、变异测试：上面几层复核真的抓得住错误吗
========================================================================================
                              变异  出错局数  违规次数  判空误判  清除率       是否报警
                  （基准，无变异）         0         0         0  1.0000 否（应当如此）
         楔形半角 1.005° -> 1.000°         2        18         0  1.0000             是
                 楔形半角 -> 0.90°        25       388         0  1.0000             是
   判空排除半径 x1.2（只改策略侧）        10        50         1  0.9969             是
                    序约束方向反转        25       149         0  0.0497             是
          排除盘线性化取消保守修正         0         0         0  1.0000       **漏检**
漏掉「收信 => 距离<=1500」与序约束         0         0         0  1.0000       **漏检**

    · （基准，无变异）：正确实现
    · 楔形半角 1.005° -> 1.000°：忽略 svd_deg 两位小数舍入，真值会被楔形排除在外
    · 楔形半角 -> 0.90°：楔形比误差界还窄，系统性排除真源
    · 判空排除半径 x1.2（只改策略侧）：把 R_eff 下界当成 1200，会把 1000~1200 m 处的真源从判空栅格里划掉
    · 序约束方向反转：把「收到信号的点更近」写反
    · 排除盘线性化取消保守修正：用切线直接当阈值，会把圆外的真源一起切掉
    · 漏掉「收信 => 距离<=1500」与序约束：少加约束不会排除真源，只会让区域偏大——应当**不**报警

    第 ⑦ 项是**阴性对照**：漏加约束只会让可行集偏大，不会排除真源，
    所以它**不应该**触发含真源检验。若它也报警，说明检验层过于敏感、
    把保守和错误混为一谈了。
