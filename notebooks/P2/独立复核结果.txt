本文件的几何全部自写，不 import 模型.py / P1 的求解函数（第 4 节除外，
那一节的目的就是把三条路径摆在一起比）。

==============================================================================
1  从定义重建定位区域，与 模型.py 的结果比对
==============================================================================
模型侧：楔形拆半平面 -> Sutherland-Hodgman 逐条裁剪。
复核侧：边界曲线两两求交 -> 用原始角度/距离定义筛点 -> 自写凸包。
两条路径除题目常量外没有共享代码。

外圈圆弧在模型侧是折线、在复核侧是真圆弧，所以允许**模型 >= 复核**的微小偏差。

    600 组随机构型：
      直径最大绝对差        = 0.009010 m
      最小覆盖圆半径最大差   = 0.004505 m
      复核顶点落在模型区域外的最大距离 = 0.000000 m
      模型直径小于复核直径（不安全侧）的组数 = 0
    -> 差异应当在圆弧折线化的厘米量级，且模型侧始终不小于复核侧。

==============================================================================
5  变异测试：把模型改错，看第 1、2 节的复核能否发现
==============================================================================
P1 的教训②：一份「看着像交叉验证」的复核可能对整类 bug 全部漏检。
这里人为植入 6 个典型错误，逐一检查复核是否报警。

第一版的抽样区间是 ρ∈[100,1400]，结果「漏掉 ρ<=1500 约束」「漏掉 ρ>5 约束」
两个变异全部漏检——因为那些构型根本没碰到这两条边界，删掉它们不改变任何结果。
这正是 P1 警告过的「看着像验证、其实测不到」。现在把抽样推到边界上：
三分之一的构型贴着远端 ρ∈[1400,1499]，三分之一贴着近端 ρ∈[5,60]。

    变异                               最大直径差(m)         漏掉的真实可行点       复核是否报警
    无变异（基准）                            0.0090                0          未报警
    楔形半角写成 0.5°                      316.7597              490           报警
    楔形半角写成 2°                        251.1049                0           报警
    漏掉 rho <= 1500 约束                294.3501                0           报警
    漏掉 rho > 5 约束                      0.2954                0           报警
    第二楔形的示向度差 0.3°                    22.6435              241           报警
    第二楔形顶点偏移 20 m                     37.8394              363           报警
    -> 基准行必须「未报警」，其余每一行都必须「报警」。
       若某个变异漏检，说明复核的独立性不够，必须改复核而不是改结论。
