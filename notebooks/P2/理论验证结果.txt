问题二 · 理论验证
随机种子 20260910；δ = 1.0°，R_eff ∈ [1000.0,1500.0] m，清除半径 20.0 m

==============================================================================
1  先验区域 Ω1 = 楔形 ∩ {5 < rho <= rho_hi} ∩ 目标圆盘
==============================================================================
Ω1 是第一次检测之后干扰源的全部可行位置，问题二的一切都在它上面展开。

① S1 在原点（问题三机器狗的出发点），示向度任意，取 theta1 = 0：
    rho 上界 rho_hi          = 1500.0 m   （由 R_eff <= 1500 决定，圆盘未起作用）
    直径 diam(Ω1)            = 1495.012 m
    最小覆盖圆半径 Rmin       = 747.615 m
    面积                     = 39269.63 m^2  （解析值 delta*(rho_hi^2-5^2) = 39269.47）
    最远端全宽 2*rho_hi*tan1° = 52.365 m
    -> 区域长 1495 m、最宽仅 52 m，是一条极细长的扇形带。
       不确定性几乎全部集中在**距离**方向上，第二个检测点的唯一任务就是定距离。

② S1 不在原点时，目标圆盘会把 rho_hi 压下来（策略随之自动缩尺）：

    -> 出发点越靠近边界、示向度越朝外，可行距离区间越短，定位越容易。

2  闭式直径公式的精度
==============================================================================
公式  d ≈ (2 tan δ / |b|) · sqrt(s²+b²) · sqrt((ρ+|s|)²+b²),  s = ρ - a
由 P1 §4.2 的  d = sqrt(w1²+w2²+2 w1 w2 |cos φ|)/sin φ  坐标化而来。
这里与精确解（Ω1 与第二楔形取交后按 P1 算法求直径）逐点对比。

3  给定前进量 a 时的最优侧移 b* 与最小直径 d_min
==============================================================================
对 ln d 关于 b 求导置零：b⁴ = s²(ρ+|s|)²，即
        b* = sqrt(|s|·(ρ+|s|)),      d_min = 2 tan δ · (ρ + 2|s|),   s = ρ - a
即：以正横站位的理想值 2ρ tan δ 为基准，沿轴每错位 1 m，直径线性增加 4 tan δ ≈ 0.0698 m。

4  交会角与正横站位
==============================================================================
P1 §4.2 已证 φ = 90° 最优。本节把它翻译成「第二个检测点该站哪」。

φ = 90°  <=>  s = ρ - a = 0  <=>  S2 落在过 G 且垂直于示向线的直线上（正横位）。
但 ρ 未知，正横位是一条**未知位置的直线**，这正是问题二的困难所在。

等宽情形下 d(φ)/d(90°) = 1/sqrt(1-|cos φ|)（P1 表），换算成沿轴错位比 |s|/ρ：
       |s|/ρ     b*/ρ      交会角φ   d/(2ρtanδ)
        0.00    0.000     90.00        1.000
        0.10    0.332     73.22        1.200
        0.20    0.490     67.79        1.400
        0.30    0.624     64.34        1.600
        0.50    0.866     60.00        2.000
        0.75    1.146     56.79        2.500
        1.00    1.414     54.74        3.000
        1.50    1.936     52.24        4.000
        2.00    2.449     50.77        5.000
    -> 沿轴错位 |s| 到 0.5ρ 时，直径已是理想值的 2 倍；错位 1ρ 时 3 倍。
       换言之：**距离估计的相对误差，几乎一比一地转成定位精度的损失**。

5  两次检测能否做到「站一点一次清除」
==============================================================================
判据（P1 §4.3）：最小覆盖圆半径 Rmin <= 20 m。必要条件 d <= 40 m。

① 两次检测的信息上限 2ρ tan δ <= 40 m  =>  ρ <= 1145.8 m，这还是把第二点放在真源正横位（ρ 已知）才有的理想值。
   更现实地，取 b = b*、沿轴错位 |s|：d_min = 2 tan δ(ρ+2|s|) <= 40 m
   =>  ρ + 2|s| <= 1145.8 m。

       ρ (m)            允许的最大沿轴错位 |s| (m)
         200                        472.9
         400                        372.9
         600                        272.9
         800                        172.9
        1000                         72.9
        1146                          nan
        1200                          nan
        1500                          nan
    -> ρ = 1000 m 时，必须事先把距离估到 ±73 m 才可能一次清除；
       而第一次检测之后距离的不确定区间长达 1495 m。**两次检测一般做不到一次清除**。

② 上帝视角扫描：**假装已知 ρ**，在 (a,b) 全平面上求精确 Rmin 的下确界。
   附加一条现实约束 |S2 - G| >= 20 m：若第二个检测点已经落进清除半径，
   直接 /clear 即可，根本不需要第二次检测，那种「最优」是自欺欺人。

==============================================================================
6  保证第二次检测收到信号的候选域
==============================================================================
已知 ρ <= R_eff <= 1500，故 R_eff >= max(1000, ρ)。于是
        |S2 - G| <= max(1000, ρ)   =>   必定收到信号
特别地 |S2-G| <= ρ（第二点比第一点更靠近干扰源）时自动成立。

对 ρ 取遍 (5,1500]，可行域是两个半径 1000 m 圆盘之交（透镜形）：
        D((5,0), 1000)  ∩  D((1000,0), 1000)
推导：ρ<=1000 段给出 ∩_{ρ} D((ρ,0),1000)，两端 ρ=5 与 ρ=1000 起作用；
      ρ>1000 段给出 ∩_{ρ} D((ρ,0),ρ)，这族圆盘全过原点且随 ρ 单调套嵌，最小者 ρ=1000。

    透镜的 x 范围: [0.0, 1005.0] m
    在 x = 502.5 处的最大侧移 |b| = 867.5 m

    蒙特卡洛校验（N = 400000，ρ 均匀、R_eff 在条件区间上均匀）：
            S2 = (a,b)     在透镜内      实测收信率     公式保证
                (0, 0)     True     1.0000     True
            (300, 300)     True     1.0000     True
            (500, 500)     True     1.0000     True
            (500, 850)     True     1.0000     True
            (502, 868)    False     1.0000    False

    -> 透镜内实测收信率恒为 1.0000；透镜外一旦距离拉开就出现漏检。
       漏检不是灾难（no_signal 也排除了一片区域），但它换不来楔形，
       所以候选区域**应当落在透镜内**，除非有意用 no_signal 做粗筛。
